Практична робота з LINQ
Мета роботи
Засвоїти принципи використання технології LINQ (Language Integrated Query) у мові програмування C# для виконання запитів до колекцій даних.

Опис проекту
Проект демонструє використання LINQ для аналізу футбольних матчів з 2010 року. У проекті реалізовано 15 різних запитів до колекції футбольних матчів, які показують різні можливості мови LINQ.

Клас FootballGame
Клас містить такі властивості:

Date - дата проведення матчу

Home_team - назва домашньої команди

Away_team - назва гостейової команди

Home_score - кількість голів домашньої команди

Away_score - кількість голів гостейової команди

Tournament - назва турніру

City - місто проведення матчу

Country - країна проведення матчу

Neutral - чи є поле нейтральним

Вимоги
.NET 6.0 або новішої версії

Newtonsoft.Json для роботи з JSON-файлами

Реалізовані запити
Запит 1
Вивести всі матчі, які відбулися в Україні у 2012 році.

Запит 2
Вивести Friendly матчі збірної Італії, які вона провела з 2020 року.

Запит 3
Вивести всі домашні матчі збірної Франції за 2021 рік, де вона зіграла у нічию.

Запит 4
Вивести всі матчі збірної Германії з 2018 року по 2020 рік (включно), в яких вона на виїзді програла.

Запит 5
Вивести всі кваліфікаційні матчі (UEFA Euro qualification), які відбулися у Києві чи у Харкові, а також за умови перемоги української збірної.

Запит 6
Вивести всі матчі останнього чемпіоната світу з футболу (FIFA World Cup), починаючи з чвертьфіналів (тобто останні 8 матчів).

Запит 7
Вивести перший матч у 2023 році, в якому збірна України виграла.

Запит 8
Перетворити всі матчі Євро-2012 (UEFA Euro), які відбулися в Україні, на матчі з наступними властивостями: рік матчу, назва приймаючої команди, назва гостьової команди, сума всіх голів за матч.

Запит 9
Перетворити всі матчі UEFA Nations League у 2023 році на матчі з наступними властивостями: рік матчу, назви обох команд через дефіс, результат для першої команди (Win, Loss, Draw).

Запит 10
Вивести з 5-го по 10-тий (включно) матчі Gold Cup, які відбулися у липні 2023 року.

Запит 11
Вивести 10 країн (без повторів) з сортуваннях від A до Z, в яких проводилися матчі у 2020 році.

Запит 12
Вивести назви турнірів, кількість ігор яких з 2022 року більша за 200. Турніри відсортувати за кількістю ігор за спаданням.

Запит 13
Вивести ТОП-3 найпопулярніших країни для проведення матчів на нейтральному полі.

Запит 14
Вивести ТОП-5 турнірів за середньою результативністю (сума забитих м'ячів).

Запит 15
Вивести команди відсортовані за алфавітом, які за весь час зіграли всього 1 гру.

Використані методи LINQ
У проекті використані такі методи LINQ:

Where() - для фільтрації даних

Select() - для проекції даних

OrderBy() / OrderByDescending() - для сортування

ThenBy() - для додаткового сортування

Take() / Skip() - для отримання частини колекції

TakeLast() - для отримання останніх елементів

First() / FirstOrDefault() - для отримання першого елемента

Last() / LastOrDefault() - для отримання останнього елемента

GroupBy() - для групування даних

Distinct() - для видалення дублікатів

Count() - для підрахунку кількості

Average() - для обчислення середнього значення

All() / Any() - для перевірки умов

Contains() - для перевірки наявності елемента

Приклад виконання
Після запуску програми в консолі буде виведено результат кожного запиту з відповідним заголовком. Кожен запит виводить свої результати у зрозумілому форматі з усіма необхідними даними.

Джерела даних
Дані взяті з файлу results_2010.json, який містить інформацію про футбольні матчі з 2010 року. Файл містить 13049 записів про матчі.
